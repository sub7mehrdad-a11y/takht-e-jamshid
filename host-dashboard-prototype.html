یاران جمشید زنده

ضحاکیانِ زنده
کارت‌های ویژه
🌑 اهریمن (ضحاک)لغوِ گفتگو/رأیِ امروز — فقط تصمیمِ مستقیمِ جمشید
⛓️ زندان (ضحاک)یه بازیکن رو تا پایانِ امروز غیرفعال کن
🕊️ سروش (جمشید)باز‌کردنِ پنجره‌ی نامه‌نگاری برای همه
جاسوسیِ ضحاک — نامه‌های این فرد اول به ضحاک نشون داده می‌شه:
🐍 چیزی که فقط به ضحاک نشون می‌دی (بدون اسمِ فرستنده/گیرنده):
📬 صندوقِ کاملِ گرداننده (برای مدیریتِ تحویل — این پنل فقط پیشِ خودته):
لیستِ بازیکنان — برای حذفِ دستی (گرسیوز / رأیِ جمشید) از دکمه‌ی کنارشون استفاده کن

حذفِ بازیکن

این عمل قابلِ برگشت نیست. علتِ حذف رو انتخاب کن:

رأی‌گیریِ مخفیِ کودتا

هرکدوم رو جدا و مخفیانه (چشم‌بسته) بپرس: «آیا قدرتِ تصمیمِ روز به فریدون منتقل بشه؟»

فرستادن به زندان

این فرد تا پایانِ امروز نمی‌تونه صحبت کنه و جمشید نمی‌تونه امروز حذفش کنه.
